# LIST OF SYMBOLS

| Symbol | Description |
| :--- | :--- |
| **$\mathbb{R}^d$** | $d$-dimensional real coordinate space (used to describe embedding vector space) |
| **$\vec{v}$** | A mathematical vector (representing a text chunk embedding) |
| **$L_2$** | Euclidean distance metric (used for vector similarity search) |
| **$\cos(\theta)$** | Cosine similarity metric |
| **$k_1$** | Term frequency saturation parameter in BM25 |
| **$b$** | Document length normalization parameter in BM25 |
| **$|D|$** | Length of the document in words |
| **$\mathcal{O}(N)$** | Big-O notation indicating linear algorithmic complexity |
| **$\Delta t$** | Time difference or latency (used for measuring Time to First Token) |
